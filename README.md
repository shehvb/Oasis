# OIBSIP - Oasis Infobyte Web Development & Designing Internship

This repository contains all task submissions for the Oasis Infobyte Internship.

## Tasks Overview

### Task 1: Landing Page
- **Folder:** `task1-landing-page/`
- **Tech Stack:** HTML5, CSS3
- **Description:** A responsive SaaS product landing page ("FlowCraft") featuring sticky navigation, hero section, features grid, about section, customer testimonials, and footer.

### Task 2: Personal Portfolio
- **Folder:** `task2-portfolio/`
- **Tech Stack:** HTML5, CSS3
- **Description:** Personal portfolio website featuring an about section, technical skills grid, featured projects with repository links, and contact information.

### Task 3: Temperature Converter Website
- **Folder:** `task3-temp-converter/`
- **Tech Stack:** HTML5, CSS3, JavaScript (Vanilla)
- **Description:** Interactive temperature conversion tool converting seamlessly between Celsius, Fahrenheit, and Kelvin with input validation and absolute zero edge-case handling.
